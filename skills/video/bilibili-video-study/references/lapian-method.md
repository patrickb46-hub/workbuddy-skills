# 拉片方法论

## 核心判断

拉片不是"看视频"，是把**画面里已经固化的决策**翻译成**下次能直接执行的动作**。
一份拉片笔记合格的标志：别人拿着它，不用再看原片也能复现同样的观感。

三条硬规矩：

1. **区分"看到"和"猜到"**。抽帧只给你离散快照。"平均镜头 2.8 秒"是从帧间距推的（可信），"她用了 L-cut"是猜的（标未验证）。
2. **单样本不出规律**。3 个以上同类型样片取交集，交集才是这个品类的通用做法，差异部分才是个人风格。
3. **写数字，不写形容词**。"节奏明快"是废话，"平均 2.8 秒/镜，前 3 秒内 4 次切换"才是规则。

## 三层拆解

### 第一层：单帧（每一帧都要过这 8 项）

| 项 | 记什么 | 怎么量化 |
|---|---|---|
| 构图 | 主体位置、留白比例 | 主体落在三分线/中心/边角，留白约占画面 1/3 还是 1/10 |
| 景别 | 特写/近景/中景/全景 | 主体占画面高度比例（>60% 特写，30–60% 近景） |
| 字幕 | 位置、字号、描边、层级 | 距底边百分比、字号占屏高比例、是否有第二层标题 |
| 配色 | 主色、色温、饱和度 | 冷暖偏向、是否有统一色调、饱和度高低 |
| 信息密度 | 一屏有几块信息 | 数文字块 + 图形块的数量 |
| 图形元素 | 进度条、角标、水印、装饰线 | 有/无 + 位置 |
| 视觉锚点 | 眼睛第一落点 | 最亮/最锐/最动的那块在哪 |
| UI 痕迹 | 软件界面占比 | 全屏录屏 / 画中画 / 无 |

### 第二层：帧序列（把帧按时间排开看曲线）

- **镜头时长分布**：相邻视觉差异大的帧之间算一次切换。求均值 + 最短 + 最长。
- **节奏曲线**：按分钟切片统计切换次数，画成柱状。看出是匀速、前密后疏，还是"钩子—铺陈—高潮—收尾"。
- **色温漂移**：全片是否统一，段落之间是否用色温区分情绪。
- **母题重复**：同一个转场、同一种字幕动效、同一个空镜是否反复出现——这是作者的签名。
- **信息节拍**：每出现一次新信息，间隔多少秒。

### 第三层：整片结构

用章节时间轴（很多 up 写在简介里）+ 抽帧对齐，回答：

- 钩子在第几秒，钩子里给了什么（结果前置？冲突？反常识？）
- 主体怎么分块，块与块之间靠什么过渡（口播？转场？章节卡？）
- 高潮/转折在哪，靠什么手段抬起来（音乐？画面密度？数据可视化？）
- 结尾怎么收（呼吁？回扣开头？彩蛋？）

## 从技法到规则

每条观察必须过这三道转换，否则不算产出：

```
观察：这段画面右下角一直有进度条
  ↓ 抽象
技法：用进度条给长内容提供"还要多久"的预期
  ↓ 定量
规则：超过 90 秒的段落，右上角放细进度条，高 4–6px，占宽 8–12%，不透明度 60%
```

只有走到第三行的才算规则。停在第一行的是观后感。

## 经验基准值（不同品类差异大，**必须用样片校准后再用**）

| 维度 | 口播/知识 | 科普/原理 | 项目展示/汇报 |
|---|---|---|---|
| 钩子位置 | 0–3s，先给结论 | 0–5s，先给反常识现象 | 0–3s，先给成品效果 |
| 平均镜头时长 | 3–6s | 2–5s（配动画可更短） | 2–4s |
| 字幕位置 | 下 1/5，居中 | 下 1/6，居中或左对齐 | 下 1/6，居中 |
| 字幕字号 | 屏高 5–7% | 屏高 4–6% | 屏高 6–8% |
| 信息密度 | 一屏 1 块 | 一屏 1–2 块 | 一屏 2–3 块 |
| 色彩 | 统一色温，低饱和 | 可用高对比强调原理 | 统一品牌色 |

这些数字是**起点不是终点**。拿到样片的中位数后，写规范时用样片的值，不用这张表的值。

## 输出物

1. **镜头表**（每 10–15 秒一行）：时间 / 景别 / 画面内容 / 字幕 / 转场 / 备注
2. **技法清单**：5–10 条，每条走完"观察→技法→规则"
3. **出片规范**：填 `assets/shooting-spec-template.md`，出片前逐条自检
4. **可信度标注**：哪些结论是抽帧直接看到的，哪些是推断的，分开列
