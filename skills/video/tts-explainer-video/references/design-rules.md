# 版式与动效规范

这份规范来自实际出片后的返工：第一版画面看着"能用"，但截图给人看时密度太高、强调色太多，
看完记不住哪句话是重点。下面每一条都是为"三秒内看懂"服务的。

## 一、颜色

只允许 **1 个主强调色 + 1 个次强调色**，其余全是灰阶。

```ts
const BG    = '#F6F5F1';  // 暖白。比纯白耐看，投影仪上也不刺眼
const INK   = '#1A1A17';  // 正文。不用纯黑 #000，纯黑在暖白上偏硬
const MUTED = '#8B8880';  // 次要信息、坐标轴、注释
const RULE  = '#DCD8CE';  // 分隔线、边框
const CA    = '#2E6E8E';  // 主强调（A 组）
const CB    = '#B04E36';  // 次强调（B 组）
const CN    = '#BFB9AD';  // 中性柱（对照组）
```

两条硬规则：
- **同一个语义永远同一个色**。A 组从头到尾是蓝，B 组从头到尾是砖红。中途换色观众要重新学。
- **灰色不是没用**。一整屏都在强调色上的时候，等于没有强调。把"不重要的"压到 28% 不透明度
  （`dim: true`），重点自己就浮出来了。

不用阴影、不用渐变、不用圆角卡片堆叠——它们只会让画面变脏。

## 二、字号阶梯

1920×1080 画布下：

| 用途 | 字号 | 字重 |
|---|---|---|
| 主标题（一屏一个） | 96–110 | 600 |
| 场景标题 | 74 | 600 |
| 结论大字 | 90–96 | 600 |
| 正文 / 旁白字幕 | 32–36 | 400 |
| 图表数值 | 44 | 600，等宽体 |
| 标签 / 注释 | 24–27 | 400 |
| 页眉页脚 | 22–24 | 400，字距 2–3px |

**最多三级同屏**。四级以上就没有层级了，只有热闹。

## 三、留白与网格

- 左边距固定 **110px**，右边距同样。所有场景共用，切场景时内容不跳。
- 内容区纵向 168–980，页眉 54、页脚 1036。**页眉页脚画在 Sequence 外面**，切场景时保持不动。
- 4px 网格。所有 left/top 用 2 或 4 的倍数，肉眼看不出来，但排版会"稳"。
- 一屏 **最多 6 个视觉元素**。超过就问自己哪个可以下一屏再讲。

## 四、动效

只有三种，别发明第四种：

| 动效 | 参数 | 用在哪 |
|---|---|---|
| 上浮淡入 | `spring({damping:22, stiffness:110})`，26px | 所有文字区块 |
| 生长 | `spring({damping:16, stiffness:90, mass:1.2})` | 柱子、进度条 |
| 画线 | `interpolate` 线性，16 帧 | 箭头、连接线 |

- **入场要有先后**：`delay = 2, 6, 12, 22...`，间隔 4–10 帧。同时出现等于没有动画。
- **时长跟旁白走**：场景有 14 秒，别让动画 1 秒就结束然后静止 13 秒。
  用 `stagger` 把柱子的生长按 1 秒一根铺开，正好对上旁白逐个数数的节奏。
- **场景切换**：默认 6 帧淡入 + 5 帧淡出（快速穿过背景色，像翻页）。
- **硬切只在一个地方用**：同一张图只换强调对象时。把前一场加入 `NO_FADE_OUT`、后一场加入
  `NO_FADE_IN`，并把已在位的柱子设成 `grow: false`——图不动、只让新的柱子长出来，
  观众会读成"同一页的下一步"，而不是"换了一页"。

## 五、图表

- **一套刻度走到底**。同一个指标的所有柱图共用 `MAXV`。数值小了柱子矮，那就矮——
  偷偷改刻度是最容易骗到观众也最容易翻车的地方。
- **数值永远标在柱顶**，不靠读者目测高度。
- **参照线比装饰强**：想说明"比对照组还差"，画一条对照组高度的虚线比在标题里写更有力。
- 没测的组别用 `—` 占位，不要画一根 0 的柱子——0 是结果，没测不是 0。
- 柱宽 190、列宽 425（四列占满 1700）。三列或五列改 `COL_W`，别改 `BAR_W`。

## 六、文字

- 一屏一句主张。标题是**结论**不是**话题**：
  「抄作业，塌了」>「L2 层的实验结果」。
- 数字用等宽体（`MONO`），跟中文黑体分开。数字对齐了，表格感才出来。
- 中文一定会显式指定 `fontFamily: '"PingFang SC", sans-serif'`。不指定 = 方块字。
- 标点用中文全角。屏幕上的文案不用句号结尾（标题、标签），正文用。

## 七、自检清单

出片前对着截图问：

1. 离屏幕一米，能不能三秒内读出这句话在说什么？
2. 强调色是不是只出现在该看的地方？
3. 有没有哪个元素是"因为好看"加的，删掉会不会更好？
4. 最后一帧是不是还留着结论？（不是纯背景）
5. 中文字形有没有变方块？
