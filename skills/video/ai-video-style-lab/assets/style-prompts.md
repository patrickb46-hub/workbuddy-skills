# 三套提示词模板（直接投给模型写渲染代码）

用法：把「角色段」+「风格段」+ 你的具体内容，一起给模型，要求它输出**一个纯函数 `draw(t)` 或一个单文件 HTML**。
不要让它输出"视频描述"，要它输出**能跑的绘制代码**。

---

## 模板 A · Clawd 系（纯代码科幻 / 情感向）

```
你是一个逐帧渲染器的作者。写一个 Python 函数 draw(t)，t 为秒，返回 1920×1080 的 PIL Image。

世界观：主角是一只像素小蟹 Clawd，身体=一个带两条腿的矩形，眼睛=两个 4×4 方块。
它住在终端里。所有画面都是代码算出来的，不允许贴任何外部图片。

视觉约束（严格遵守）：
- 底色 #0A0A0C，允许极淡的网格线（透明度 6%）
- 只用两个彩色：琥珀 #E8A06A（主角/主高光）、青绿 #7FD8C4（对立面/数据）。第三色用白。
- 左上角：编号+章节名（"01 | 切分"）+ 一行英文小注，等宽字体
- 右上角：一个实时变化的读数（如"上下文 0.8%"/"迭代 2841/30000"）
- 底部居中字幕，最多两行，关键词高亮
- 字体：粗几何无衬线中文；数字用等宽

节奏：平均 3–4 秒一次视觉变化；抽象概念必须有一个可抓住的形状
（隧道=层层向内收的方框；粒子=被压缩的字；点阵=脸）。

内容：[在此填入你的原理/情节]
要求：先输出参数区（颜色、字号、边距常量），再输出 draw(t)，再输出主循环与 ffmpeg 导出命令。
```

## 模板 B · 编年史系（时间压缩 / 教学）

```
写一个单文件 HTML（Canvas 2D），全屏 1920×1080，用于一集"AI 编年史"。

恒定装置（每一帧都在）：
- 右上角巨大年份，字号=屏高 13%，等宽，右对齐，颜色 #E3B341
- 左上角事件标签："事件名 · 年份"，12px 上划线
- 底部一条年代刻度轴（1940→2026），刻度密度随时间加速而变密
- 中部：一条发光指数曲线，散点=里程碑，当前年份的点最亮
- 左侧字幕块，左对齐，一次两行

颜色只有三种：#000 底 / #E3B341 主 / #B8B8B8 注释。任何想加色的地方，改成提高明度。

叙事：前 70% 时间按年代匀速推进（每年约 4 秒）；后 30% 进入"加速段"，
年份切换间隔从 20 秒压到 0.4 秒，背景叠加满屏论文标题文字流（透明度 20%），
前景压一句大字（例如"719 篇" / "借过一下。"）。

终点：曲线接近垂直，画面留白 2 秒，给一个开放式问句作字幕，然后黑场。

内容：[在此填入时间线节点]
要求：输出完整可直接打开的 HTML，所有参数抽成顶部常量对象。
```

## 模板 C · 等距线稿系（长片 / 严肃概念）

```
写一个 Python 逐帧渲染器（PIL 画线），出 1920×1080，用于一部长片的第 N 章。

造型语言：等距投影（30°）线框，无贴图无阴影。人物=火柴人（圆头+4线，绝不画五官）。
道具=最小几何：钱堆=叠矩形，房子=三角+方框，车=两轮+梯形。
一条贯穿全幅的地平线，所有元素站在上面。光源固定一个，右下偏上，暖橙 #FF7A2F 径向光晕。

颜色：黑底 #0B0B0C / 线 #D8D6D0 / 唯一暖光 #FF7A2F。全片不超过这三色。
（若本章是"情绪反转段"，允许整章换成米白底 #F2EEE6 + 深褐线 #3A332B，但全片只许一次。）

恒定装置：
- 左上角三层章节面包屑："一 · 财务自由怎么算 / 4% 法则 / ① 资产"
- 数据浮标直接挂在几何体上，带单位（100万 / 400万 / 3%），可疑的数字加"？"
- 错误选项上打红色 X
- 底部居中一行字幕，不换行

节奏：一帧只允许出现一个新元素；元素进场=淡入 + 位移 20px；每章开头静止 2 秒章节卡。

本章内容：[在此填入论点、反例、结论]
要求：先输出版面几何常量（地平线 y、安全边距、字号），再输出逐场景函数，最后输出 ffmpeg 命令。
```

## 通用追加句（每次都要带）

```
三条硬约束：
1. draw(t) 必须是纯函数，只依赖 t，不允许随机数（要随机用固定 seed）。
2. 字幕距底边 ≥ 8%，左右 ≥ 6%，任何一帧不允许压住主体。
3. 结尾 1.5 秒静默/黑场，不加任何"点赞关注"。
输出后自检：颜色数 ≤3、单帧信息块 ≤2、每个数字有单位。
```
