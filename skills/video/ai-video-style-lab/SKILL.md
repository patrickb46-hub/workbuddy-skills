# AI 视频风格实验室

## 何时用

- 要按某个具体创作者的路子做视频（"照 plotome 那种做一个""要 Clawd 那种感觉"）。
- 要做 AI 主题的短片：原理讲解、发展史、概念可视化。
- 需要判断"这个选题该用哪种视觉语言"，或现有片子"差点意思"缺什么。
- 需要把一集视频拆成分镜表、写成可渲染的代码。

**不适用**：真人出镜、实拍纪录、纯商品广告（这三套都太"冷"）；也替代不了文生视频抽卡——那是另一条路。

## 选哪套：三个问题就够

1. **有角色吗？** 有 → A。没有但有时间线/数量级 → B。都没有、要讲清一个道理 → C。
2. **多长？** <2 分钟 → A（他最会做短）。5–8 分钟 → B。>15 分钟 → C。
3. **要情绪还是要求知？** 要人心里"闷一下" → A。要人"看懂了" → B。要人"存下来慢慢看" → C。

不确定时的默认：**讲 AI 原理 → A；讲 AI 历史 → B；讲一个决策/钱/风险 → C。**

## 共同的五条铁律（三家都遵守，这才是能提分的地方）

1. **不是文生视频，是让模型写渲染代码。** 逐帧确定性出片，每个像素可控。这条路省钱是次要的，可控是主要的。
2. **一位固定主角 + 一套固定视觉语法。** 跨片复用，才有品牌复利。每集换风格等于每集从零开始。
3. **数字即叙事。** 0.7 秒 / 33 个宇宙 / ≈1/10000 / 208 万。模糊形容词一律换成带单位的数。
4. **深色底 + 单点高光 = 低成本高级感。** 三色封顶；想加色就提高明度，不引入新色相。
5. **结尾必须静下来。** 黑屏、反转底色、或一句人话。绝不用"点赞关注"打断情绪。

## 生产流程

1. **定风格**：用上面三个问题选 A/B/C，不要混。
2. **写主张**：一句话，能被反驳的那种（"所以百分之三，不是中国版的百分之四"）。
3. **填分镜**：`assets/shot-list-template.md`，一行一个镜头，一帧一个新信息。
4. **出代码**：用 `assets/style-prompts.md` 里对应模板，让模型输出 `draw(t)` 或单文件 HTML。要求纯函数、无随机。
5. **渲染**：见 `references/code-render-pipeline.md`。先跑 `ffmpeg -version`，本机 ffmpeg 曾因缺 `libxcb.1.dylib` 挂掉。
6. **自检**：颜色 ≤3、单帧信息块 ≤2、每个数字有单位、字幕在安全区、结尾静默 1.5 秒。

## 常见坑

- **想用实拍素材**：一帧真素材就毁掉"这是算出来的"的可信感。全代码，或者干脆走另一条路。
- **字幕居中大字**：只有 A 能这么干。B/C 用左对齐或底部单行，否则气质立刻变"短视频"。
- **给火柴人画脸**：C 的火柴人一有五官就变成儿童插画。
- **加速段解释细节**：B 的加速段只给密度，不给理解，解释留到前后段。
- **录屏掉帧**：核对 `帧数 ≈ 时长 × FPS`，差超过 2% 就重录。

## 证据与诚实边界

三份档案里的每个结论都标了"抽帧时点"，可回溯复核。以下内容**没有**验证，引用时必须说明是推断：
运镜速度、转场类型（抽帧只有离散快照）、BGM 具体曲目与和声、旁白是否为真人、创作者使用的模型版本细节。

样本量提示：B 只有 2 个稿件，A 有 7 个，C 只有 1 个 46 分钟长片。C 的"长片结构"结论基于单一样本，属于强假设。
