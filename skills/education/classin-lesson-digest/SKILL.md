# 课堂截图 → 结构化笔记 + 答题方法 docx

## 这个技能解决什么

ClassIn 笔记助手（`~/Desktop/Tools/ClassIn笔记助手/`）上课时把板书截成一张张图片，按课时归好类，
点「保存到「黄老师语文」」后会落到：

```
~/Desktop/黄老师语文/<YYYY-MM-DD>/01_例题.png  02_练习.png  03_知识点.png …
（同级还有个隐藏文件 .lesson_index.json，记录这天的课时与文件清单）
```

图片只是图片，翻起来还是要一张张看。这个技能把它们变成两样东西：

1. **`课堂整理_<日期>_第N节.html`** —— 分好类的图文笔记：例题带解析、习题带答案、知识点成条，可打印、可存 PDF
2. **`~/Desktop/黄老师语文/答题方法汇总.docx`** —— 跨课时累积的通用方法库，每次自动去重合并

## 环境

```bash
PY=python3
SK=~/.workbuddy/skills/classin-lesson-digest
ROOT=~/Desktop/黄老师语文          # 笔记助手的保存位置，可在界面里改
```

依赖：`pyobjc-framework-Vision`（OCR，离线）、`python-docx`、`Pillow` —— 都已装在这个解释器里。
**必须用上面这个 `$PY`**，系统 python3 没有这些包。

## 工作流

### 第 0 步：找要处理的课时

```bash
ls -d "$ROOT"/[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9] 2>/dev/null
```

- 用户指定了日期/课时 → 就处理那个目录
- 用户说「整理今天」「整理上一节课」→ 取最新且**没有 `.digest.done`** 的目录
- 目录里有 `.digest.done` 说明已经整理过；除非用户要求「重新整理」，否则跳过

### 第 1 步：OCR（离线，几秒一张）

```bash
$PY $SK/scripts/ocr.py "$ROOT/2026-10-21" --json /tmp/ocr_20261021.json
```

stdout 会按 `===== 01_例题.png =====` 分块打印全部文字，直接读它即可，不用再开图。
识别质量受截图分辨率影响；公式、生僻字、手写体可能出错，**不确定的地方以原图为准**。

### 第 2 步：把文字整理成结构

按内容判断（不要只依赖文件名里的类别，文件名只作参考）：

| 类别 | 判断标准 | 输出形态 |
|---|---|---|
| **例题** | 老师讲解、有完整解析或板书推导的题 | 题干 + 分步解析 + 结论 |
| **习题** | 留给自己做、只有答案或提示的题（课堂练习、课后作业、当堂检测） | 题干 + 答案（有解析就一并给） |
| **知识点** | 定义、文体常识、手法术语、默写要点、易混辨析 | 短条目，一条一句 |
| **答题方法** | 可迁移的步骤 / 模板 / 公式化范式（"三步走""先…再…最后…"） | 方法名 + 步骤 |

硬性要求：

- **题与解答要配对**。同一个板书里题目和解析通常相邻；OCR 是按版面从上到下出的，顺序基本就是讲课顺序。配不上时，把解析挂到最可能的那道题下并在末尾标 `（配对存疑）`
- **不要编造内容**。OCR 没读出来的部分留 `……`，不要用常识补；补充的推断必须写成 `（按上下文补：…）`
- 数字、文言原句、引号内的话**逐字保留**，不要改写
- 合并重复：同一道题在多张图里重复出现时只留信息最全的一次

### 第 3 步：写 notes.json，交给渲染器出 HTML

**不要手写 HTML**——用固定渲染器，版式才不会每次都不一样。

```json
{
 "date":"2026-10-21","lesson":"第 1 节","subject":"语文","teacher":"黄老师",
 "title":"《与朱元思书》：字词落实与写景手法",
 "summary":"一句话说明这节课重点（30~60 字）",
 "examples":[
   {"no":"例 1","title":"翻译：风烟俱净，天山共色。",
    "answer":"俱：都。净：消散。共色：同样的颜色。\n译：风停了……",
    "tags":["文言翻译","实词"],"image":"01_例题.png"}
 ],
 "exercises":[
   {"no":"练 1","title":"课堂练习","question":"① 默写：……\n② ……",
    "answer":"① ……\n② ……","tags":["默写"],"image":"03_练习.png"}
 ],
 "points":[{"title":"通假字","text":"蝉则千转不穷……"}],
 "methods":[{"title":"文言翻译四步","steps":["① 留：……","② 删：……"],"image":"05_答题方法.png"}],
 "images":["01_例题.png","02_例题.png","03_练习.png","04_知识点.png"]
}
```

```bash
$PY $SK/scripts/render_notes.py --data /tmp/notes.json \
    --out "$ROOT/2026-10-21/课堂整理_2026-10-21_第1节.html"
```

规则：

- 字段除 `date` / `title` 外都可省；**空板块会自动隐藏，目录同步收缩**，没讲例题就不写 `examples`
- `answer` 里的换行用 `\n`；渲染器会转成 `<br>`
- `image` 只写**文件名**（和 HTML 同目录），不要绝对路径
- 没被任何卡片引用的图会自动收进「原始截图」，不会丢
- 渲染器会打印「仍有 N 个占位符」，正常应该是 0
- 样式源在 `$SK/assets/template.html`（宋体、A4 打印、图片最大高 460px、可切「只看文字」）；
  想改配色/字号改那里，别改脚本里的 CSS

### 第 3.5 步：自检

```bash
cd "$ROOT/2026-10-21"
grep -o '__[A-Z][A-Z_]*__' 课堂整理_*.html | head        # 应为空
ls *.png | wc -l                                        # 图张数对不对
```

再用浏览器打开看一眼：图片是否都能显示、例题解析是否配错题、有没有空卡片。

### 第 4 步：抽出答题方法 → 合并进 docx（自动去重）

只把**通用、可迁移**的东西写进 `items.json`。具体某道题的答案不算方法。

```json
[
  {"key": "文言文-实词定位", "section": "文言文阅读",
   "title": "翻译题先定位实词", "body": "① 圈出句中实词、虚词\n② 先直译实词，再调整语序\n③ 省略成分补出来，用括号标明",
   "source": "2026-10-21 第1节"}
]
```

- `key` 是稳定标识：`<板块>-<方法短语>`，**同一个方法每次都用同一个 key**，这是去重最可靠的一道保险
- `section` 决定它在 docx 里的分组（文言文阅读 / 现代文阅读 / 古诗鉴赏 / 写作 / 基础积累 / 通用）
- `title` 一句话，`body` 分步骤，一步一行

```bash
$PY $SK/scripts/merge_methods.py --items /tmp/methods.json \
    --docx "$ROOT/答题方法汇总.docx"
# 其他有用开关
$PY $SK/scripts/merge_methods.py --docx "$ROOT/答题方法汇总.docx" --list      # 看看现在收了什么
$PY $SK/scripts/merge_methods.py --items /tmp/methods.json --docx ... --dry-run  # 只演算不写入
```

脚本会打印「新增 X · 重复跳过 Y · 补全 Z」，重复判断依次看：key → 标题相似度 → 全文相似度 → 同板块正文相似度；
新版本明显更完整时用新的覆盖旧正文，来源会累加。**不要自己手改 docx**，改索引就等于改内容。

### 第 5 步：打标记

```bash
echo '{"done":"'$(date +%FT%T)'","html":"课堂整理_2026-10-21_第1节.html"}' \
  > "$ROOT/2026-10-21/.digest.done"
```

有了它，定时任务下次就知道这节已经处理过，不会重复生成。

## 定时任务怎么建

用户要「以后自动整理」时，用 `automation_update` 建一个**每天固定时间**的重复任务（本地没有文件监听，
所以用时间兜底：晚上扫一遍今天有没有新导出的课时目录，没有就静默结束）。

```json
{
  "mode": "create",
  "name": "语文课堂笔记整理",
  "scheduleType": "recurring",
  "rrule": "FREQ=DAILY;BYHOUR=21;BYMINUTE=30",
  "status": "ACTIVE",
  "prompt": "用 classin-lesson-digest 技能整理今天的语文课堂笔记：在 ~/Desktop/黄老师语文 下找今天日期（YYYY-MM-DD）的文件夹，若不存在或已有 .digest.done 就直接结束、不要输出任何文件；否则对该文件夹做 OCR，按技能规范写出 notes.json 并用 render_notes.py 渲染成「课堂整理_<日期>_第N节.html」，再把可迁移的答题方法用 merge_methods.py 合并进 ~/Desktop/黄老师语文/答题方法汇总.docx（自动去重），最后写入 .digest.done。结束时用三行说明：生成的文件路径、整理出几道例题/习题、答题方法新增与跳过各几条。"
}
```

- 想改成「每节课后 10 分钟」不现实（课表不固定），宁可定在晚上一个固定时间
- 用户临时要整理：直接说「整理今天的语文笔记」，走同一个技能，不必等定时任务

## 排错

| 现象 | 处理 |
|---|---|
| `No module named 'Vision'` | 用错了 python，必须 `$PY` |
| OCR 全是乱码/空 | 截图分辨率太低或被压缩过；用原图（`.png`）别用 `.jpg` |
| 目录里没有 `.lesson_index.json` | 不是从笔记助手导出的，直接按文件名顺序处理即可 |
| docx 打不开 | 确认没被 Word 占用后重跑；或 `--rebuild` 按索引重建 |
| 占位符没替换干净 | `grep -o '__[A-Z][A-Z_]*__' 文件.html` 自查；正常应为空 |
| 页面没图 / 图裂了 | 图必须和 HTML 同目录；`image` 字段只能写文件名 |
