怎么用？（点开看一眼就行）
  • 典型流程：左栏点进「学科 / 组名 / HEIC」→ 全选 → 选「同级 JPG 子目录」→ 开始处理。输出的 JPG 会和 HEIC 并排放在 JPG/ 里，原图照旧。
  • 照片拍歪了：用「微调角度」，比如 2.5°，会自动补白底、不留黑角。
  • 一页拍不全：先用「快速切半」框好，再勾「上下切两张」，一次输出两张。
  • 只想看看效果：点「先看效果（不落盘）」，不写任何文件。
  • 所有转换、裁切都在你本机的 Python 里算，不联网、不上传；HEIC 用的是 macOS 自带的解码能力。
  • 缓存目录 ~/Library/Caches/试卷图片处理工具，嫌占地方可以直接删，工具下次会自动重建。
