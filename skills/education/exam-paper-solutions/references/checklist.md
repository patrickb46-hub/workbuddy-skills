# 交付前自检清单

**机检优先**：`check.py` 全部 OK 就不用再逐条肉眼翻。下面是机器查不到、必须人（模型）判断的部分。

## 一、机检（一条命令）

```bash
PY=$HOME/.workbuddy/binaries/python/envs/default/bin/python
SK=~/.workbuddy/skills/exam-paper-solutions
$PY "$SK/tools/check.py" "$GROUP_DIR"          # 目录里所有 html 一次查完
```

它查：div 配平、id 唯一、`<details>` 残留、四段齐全、`fd-sol` 类、`.restate` 存在、「如图／同上／见上」出现、`.qbtn` 的 `data-target`、`.qhd.q`、答案速查表、考点块完备性、配套题数量、`＿＿＿＿`、目录锚点、两个组件是否注入、模板占位符残留、打印全展开规则。

`FAIL` 必须清零；`WARN` 逐条判断（"没有 key"在要分享时才算问题）。

## 二、人工判断（机器查不出）
