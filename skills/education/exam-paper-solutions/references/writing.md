# 写作细则（全解四段 ／ 考点知识点 ／ 英语卷）

SKILL.md 只留硬规则，这里放展开说明。**只在需要判断"这段该写什么"时读。**

## 一、四段各写什么（不许串味）

| 段 | 内容 | 禁止 |
|---|---|---|
| **辅助线** | 作哪个点／连哪条线／建什么系，一句话一条，附一句"为什么是它" | 写算式、写结论 |
| **思路** | 拆成 3–5 个小步，每步标题＝这一步干什么，内容一句话 | 抄完整解答的推导；给数值 |
| **答案** | 仅最终答案一行（多问分行） | 夹带过程 |
| **完整解答** | 开头把辅助线原样重述（作图语句），再分步 + 逐句，每句句末括号注依据 | 用"如图""同上""见上"指代；省依据、省单位 |

用 `.mk` 规格写的时候，这几段的边界由脚本强制，你只要按 `@aux / @idea / @ans / @sol` 分开写：

- `@aux` 里 **`~` 开头的行**是"为什么画这条"的解释，脚本会自动把它排除在「作图重述」之外 —— 懒一点也要写清楚。
- `@ans` 只写**最终答案**，脚本会自动铺到三处（答案段／解答末尾的「答：」／答案速查表），不要自己重复写。
- `@idea` 一行一个小步，格式 `标题 | 一句话`。
- `@sol` 里 `## 标题` 变分步标题，其余每行一段；**行末括号自动变成绿色依据**（`.rs`），不想让它变绿就在行尾加 `\`。
- **纯代数题没有辅助线**：`@aux` 留空即可，脚本会自动写一句「本题不需要辅助线，直接按定义与公式推进」，
  并且不生成作图重述（`check.py` 也不会判它缺项）。想写自己的说法就正常填 `@aux`。

## 二、证明题的依据怎么写

- 一句一行，句末括号写**具体定理名**：等式性质、垂直的意义、三角形内角和、SAS、AAS、HL、等腰三角形三线合一、斜边中线定理、韦达定理、判别式、勾股定理逆定理……
- 禁止"显然""由题意""易得"。
- 同一题里第二次用同一依据，可以写"同上依据"？**不行** —— 写全（"勾股定理"就四个字，不费打字）。

## 三、答案与其他硬项

- 最终答案用 `.final`（脚本对 `@ans` 自动加框加粗）；多解全写（"22.5° 或 67.5°"）。
- 末尾必有**答案速查表**（脚本自动生成）。
- 分步小标题用"第一步／第二步"；"同理"单独成块并说明是本节内部编号。
- 单位不许省：几何长度写 cm，角度写 °，面积写 cm²。

## 四、英语卷

- **全文中英对照**：题干英文 + 灰色中文（`.zh`）、选项逐项给中文、答案先英文再中文、解析中文 + 语法术语括注英文（"定语从句 relative clause"）。
- 答案速查表加"中文"列。
- 用 `.mk` 时把中文写在英文后面同一行即可，或在该行 `<span class="zh">中文</span>`。

## 五、考点·知识点 HTML（第二份，必出）

用 `build.py kp`：`%title/%meta` + `@sect` 分节 + `@kp` 每块 + `@k` 知识点 + `@tip` 易错 + `@eg` 例题 + `@q` 练习。

规则（脚本管结构，人管内容）：

- **每题一块**（含小问），题号与全解完全一致。块内三类信息：
  - **考点**：题型 + 方法，动宾短语（`@kp 第 N 题 | 考点 | 难度★`）
  - **知识点**：准确表述 + 公式，几何写全"条件→结论"（`@k 知识点① | …`）
  - **易错点**：`.kp-tip`，真没有就写 `—`，**不许编**
- 按题型分节，节末「本节考点小结」表、全卷末「考点分布表」＋条形图 —— **脚本自动生成**，别手写。
- **每条知识点配 2–3 道配套题**：例题 1–2（思路→步骤逐行→答案加框）＋练习 1–2（只给答案）。
  **不得与原卷重复、不得只改数字、不得掺别的知识点。**
- 英语卷同样中英对照。
- 顺序**先全解、后考点表**（考点要按定稿题号对齐）。

## 六、难度星星怎么给

★ 直接套公式／一步到底；★★ 需要两步转换或选一个模型；★★★ 需要分类讨论／作辅助线／构造。

## 七、手写路径（脚本不适合时）

个别题（大段非常规排版、多图并排）用 `.mk` 别扭时，可以只把那一题手写成 HTML 片段，其余走脚本，或直接改渲染后的 HTML。手写时仍然：

- 折叠只用 checkbox（`<input class="fd-cb">` ＋ `<label class="fd-hd">`），**禁用 `<details>`**（打印压不开）。
- id 全局唯一：`f{题号}-aux / -idea / -s{n} / -ans / -sol`。
- 「完整解答」那个 `.fd` 必须带 `fd-sol` 类。
- 题号必须写在 `.qhd.q` 里（搜索定位依赖）。
