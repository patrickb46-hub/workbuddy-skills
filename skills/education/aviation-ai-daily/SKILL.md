# aviation-ai-daily · 每天一节，为蓝天铺路

给一位**初中在读、零基础**的学员，每天一节约 10 分钟能读完的课。
主线是航空（他的目标是"能开飞机 + 想懂设计与工程"），第二条线是 AI 与软硬件研发。
**双线交替**：第 1 课航空、第 2 课 AI、第 3 课航空……两条线各自独立推进。

## 三条不能破的规矩

1. **当零基础教，且主动纠偏。** 他不缺零散知识，缺的是被校正过的体系。每节课必须有「常见错误认知」模块，
   且至少纠正一条**真实存在**的误解（不是编个稻草人来打）。宁可少讲，不能讲错。
2. **准确性优先于生动。** 只引用权威来源（NASA / FAA / EASA / CAAC / 波音空客官方 / 经典教科书 / 官方文档 / arXiv）。
   凡是简化模型、存在争议、或还在演进的，正文里**明写**"这是简化说法"或"目前仍有争论"。
   拿不准的概念就不写，换一个讲得准的。
3. **断网也能看。** 单文件 HTML，图全部内联 SVG，不引任何外链图片/字体/CDN。

## 产出位置

所有课件平铺在一个文件夹里，按"日期 + 课号"命名，索引就在旁边：

```
~/Desktop/每日简报/Daily Lesson/
  index.html                                  ← 索引页（复习入口，带筛选）
  2026-10-30_A01_飞机为什么能飞.html
  2026-10-31_B01_什么是AI.html
  ...
```

硬规则：
- 文件名格式 `YYYY-MM-DD_<课号>_<中文短标题>.html`。日期在最前，按名称排序就是时间顺序。
- 短标题取 8–12 字，**去掉**空格和 `/ \ : * ? " < > |` 这些字符（中文文件名里带它们会出问题）。
- 课号（A01/B01）必须在文件名里，复习时一眼能看出进度和线别。
- 同目录只写自己的课件和 `index.html`，不要动别的。
- 凌晨 3:00 生成，日期取**当天**：11 月 1 日 03:00 生成 → `2026-11-01_...`。
- 不要往 `每日简报/YYYY-MM-DD/` 那些日期文件夹里塞课件——那里只放当天简报和附件。

## 工作流（每次执行按顺序做完）

### 1. 定课号
读 `~/.workbuddy/skills/aviation-ai-daily/state/progress.json`：

```json
{ "next_index": 1, "history": [ {"date":"", "no":1, "track":"aviation", "code":"A01", "title":"", "file":""} ] }
```

- 全局第 `n` 课：`n` 为奇数 → **航空 A 线第 (n+1)/2 课**；`n` 为偶数 → **AI B 线第 n/2 课**。
- 课题目录见 `references/curriculum.md`，按编号取，**不跳课、不重排**。
- 若 `history` 已有今天日期的记录 → 说明今天已上过，**直接告知用户并展示路径，不重复生成**。
- 80 课走完后进入二期：同样的主题换更深的角度，或按他近期提问的兴趣点自由延伸，继续递增 `next_index`。

### 2. 选题与查证
- 从 curriculum 取本课"学完能回答"的那句目标，**只解决这一句**。
- 动手前至少核实 1 个关键事实（用 WebSearch/WebFetch 查官方页面或权威教材），把来源 URL 记下来。
- 若本课主题涉及具体数字（速度、温度、年龄、规章条款），逐个核对；核不到就换成不依赖具体数字的讲法。

### 3. 画图
每课 **2–3 张内联 SVG**，至少第 1 节必须有图。要求：
- 手绘风格的功能框图、剖面示意、坐标曲线、时间轴，不追求美术精度，追求**一眼看懂关系**。
- `viewBox="0 0 640 300"` 左右，`width:100%` 自适应；文字用 `font-size` 14–16，中文别超过 3 行。
- 每个图形元素显式写 `fill` / `stroke`，**不要依赖 CSS 类**（模板里没有图表色板）。
- 颜色跟主题走：航空线蓝 `#2f6fdb`，AI 线紫 `#6b4fd8`，中性灰 `#5c6470`。

### 4. 写内容
先 Read `assets/lesson-template.html`，再按它的结构产出**新文件**（不要直接改模板）。替换全部占位符，正文 3–5 节。

写作要求：
- 开头 `{{SUBTITLE}}` 必须是一句人话，不是术语堆叠（"为什么抬头太多反而会掉下去" ✔ / "迎角与失速关系浅析" ✘）。
- 每节一个小标题，讲一个因果链：**是什么 → 为什么 → 所以会怎样**。
- 用他能感知的类比（骑车压弯、放风筝、开车跟车距离），但类比之后必须补一句"类比的边界在哪"。
- 「只记这三条」是全课精华，必须能单独成立。
- 「动手 10 分钟」要是真能做的事（纸飞机改一个角度、画一张框图、算一个数、在浏览器里跑一段代码），并附折叠提示。
- 每课结尾给 1 行明天预告，和实际下一课对应。

### 5. 落盘与校验
- 路径：`~/Desktop/每日简报/Daily Lesson/YYYY-MM-DD_<课号>_<短标题>.html`。
- 写完后自查（用 Grep 查残留）：
  - 文件里**不能有** `{{` 或 `}}` 残留；
  - 不能有 `http` 出现在 `<img src>` / `link rel="stylesheet"` / `script src` 里（正文里的来源链接可以）；
  - `<html` 与 `</html>` 成对，`<svg` 与 `</svg>` 数量一致。
- 更新 `state/progress.json`：`next_index` +1，history 追加一条（`file` 写完整绝对路径）。
- 更新 `~/Desktop/每日简报/Daily Lesson/index.html`：在 `<!-- LESSONS:START -->` 与
  `<!-- LESSONS:END -->` 之间，把新条目插到**最上面**（最新的在顶部）。每个 `<li>` 四个关键字段：

  ```html
  <li class="lesson" data-track="aviation">   <!-- 或 ai -->
    <a href="2026-11-01_A02_机翼与失速.html">   <!-- 相对路径，文件名原样 -->
      <div class="row">
        <span class="tag">航空 · A 线</span>      <!-- 或 AI · B 线 -->
        <span class="date">2026-11-01</span>
        <span class="no">A02</span>
      </div>
      <p class="t">课标题</p>
      <p class="d">一句话副标题</p>
      <p class="kp"><b>记忆点</b>　三条记忆点，用 · 隔开</p>
    </a>
  </li>
  ```

  同时把顶部 `<div class="stats">` 里三个数字（总课数、A 线、B 线）各加一，别忘改。
  `.kp` 那一行是给复习用的，必须写——他翻索引时不用点进去就能回忆要点。

### 6. 交付
用 `present_files` 打开当天课件，正文回复里给三行：今天讲了什么、三条记忆点、明天讲什么。
**不要**把整篇课件内容复述到对话里——他要的是读课件，不是读聊天记录。

## 已知坑

- 模板里 `.mistake` 只能有 1–3 条纠偏，写多了页面变红、重点被稀释。
- 中文标题不要超过 22 字，超过在 560px 窄屏会折成三行压住副标题。
- SVG 里 `<text>` 不换行：长句要手动拆成多个 `<text>` 或缩短。
- **流线与物体轮廓至少要留 12px 间隙**。贴得太近，浅色流线会看起来像"穿进翼型内部"——
  第一课就踩过这个坑，重画了三次。标注点（圆点）要落在轮廓**外侧** 2–4px，落在线上会显得在物体内部。
- SVG 里的公式不要写 `C_L`，用 `<tspan font-size="14" dy="5">L</tspan>` 做下标；HTML 正文里用 `<sub>`。
  零基础学员会把 `C_L` 当成代码。
- 正文里千万别混 Markdown 的 `**粗体**`——在 HTML 里会原样显示星号。一律用 `<strong>`。
- 截图自查命令（macOS，绕开 GPU 崩溃必须带 swiftshader 参数）：
  ```
  ~/Library/Caches/ms-playwright/chromium_headless_shell-1234/chrome-headless-shell-mac-x64/chrome-headless-shell \
    --no-sandbox --disable-gpu --disable-gpu-compositing --in-process-gpu \
    --use-angle=swiftshader --enable-unsafe-swiftshader --hide-scrollbars \
    --window-size=900,4800 --screenshot=/tmp/check.png "file:///<课件绝对路径>"
  ```
- 不要为了"生动"编造故事、人物对话或事故细节。航空史的真实案例足够精彩，但**必须是真的**。
