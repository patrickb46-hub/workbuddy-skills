# 需求清单与变更记录

本文件是「用户到底要什么」的唯一账本。用户每提出/修改一条要求，按下面三步处理：
1. 在「当前需求」里改对应的条目；
2. 在「变更记录」追加一行（日期 / 变更点 / 影响到的文件）；
3. 同步 SKILL.md 与工作区记忆。
