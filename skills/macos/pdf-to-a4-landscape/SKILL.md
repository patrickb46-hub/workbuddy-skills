# PDF 照片 → A4 横版满幅重排

## 默认参数（用户 2026-09-30 明确指定：**不要问，直接做**）
遇到这类需求**直接开干，不要用 AskUserQuestion 逐项确认**，按以下默认值执行：

| 项 | 默认值 |
|---|---|
| 缩放方式 | **fit —— 等比放大不裁切**（宁可留最小对称白边，也绝不切掉内容） |
| 纸张 | **A4 横版 297×210mm**（除非用户明说竖版） |
| 输出格式 | **PDF**（不额外导出 PNG） |
| 输出位置 | **源文件同目录** |
| 文件名 | `<原文件名>_A4横版.pdf` |
| 图像处理 | **不重采样、不锐化、不重新压缩**，直接搬运原始 JPEG 字节流 |

做完之后**照实汇报**就行：成品尺寸、白边/裁切量、有效 DPI、原图本身是否带黑边等瑕疵；要改（裁边、换纸张、出图片版）用户会自己说。

## 什么时候用
用户手里有一份 PDF（多是 jsPDF / 打印工具 / 扫描 App 生成的），里面**每页嵌了一张照片或扫描件**，但照片没占满纸张——典型症状是「只占了页面上半部分，下半页全白」，或者照片被塞在竖版 A4 里显得很小。用户想把照片铺到 A4 纸上，横版或竖版。

## 核心手段：纯标准库字节级重建
**不要用 PyMuPDF / Pillow 重新插入图像**——那有可能触发重编码，损失画质。正确做法是：

1. 按源 PDF 里每个图像对象的 `/Length` **精确切出原始 JPEG 字节流**（`/Filter /DCTDecode` 直通搬运）；
2. 新建一份极简 PDF：每页一张图，`MediaBox` 改成目标纸张尺寸；
3. 用 `cm` 矩阵把图像等比缩放到目标版面。

这样**图像比特级不变**（可用 SHA-256 验证），且零依赖、零联网。

## 用法
```bash
python3 scripts/rebuild_a4_landscape.py <源.pdf> <输出.pdf> [fit|cover]
```
- `fit`（默认）：等比放大到不裁切，留最小的对称白边 —— **推荐默认**，因为不会切掉内容。
- `cover`：等比放大到铺满整页，多出来的部分裁掉。

脚本会自动按页面顺序抓出内嵌图片、自动按比例算坐标，并打印每页的成品尺寸与白边/裁切量。

## 四种常见纸张
改脚本顶部的两个常量即可：

| 目标 | PAGE_W | PAGE_H |
|---|---|---|
| A4 横版（默认） | 841.89 | 595.28 |
| A4 竖版 | 595.28 | 841.89 |

| Letter 横版 | 792 | 612 |

## 关键坑（踩过）
1. **必须先备份/确认不覆盖原文件**。新建输出文件，源文件保持不动。
2. **xref 偏移必须用 `len(out)` 现场记录**，不能手算。xref 每行**恒为 20 字节**（`%010d 00000 n \n`），空闲项 `0000000000 65535 f \n` 也必须 20 字节——少一字节后续全错。
3. **全程 `bytes`/`bytearray` 拼接 + `Path.write_bytes()`**。任何一步经过 `str` 或文本模式都会把 0x80–0xFF 破坏成 UTF-8 多字节，JPEG 立刻损坏。结构串转字符串只允许 `latin-1`。
4. **`/Length` 一律用运行期 `len()`**，不硬编码。
5. **不要加** `/DecodeParms << /ColorTransform ... >>`——DeviceRGB + DCTDecode 是 PDF 核心能力，加了反而偏色。
6. **不要加 `/Rotate`**，方向完全由 `cm` 矩阵决定。
7. `stream` 关键字后必须紧跟换行，数据后紧跟 `endstream`。JPEG 字节里混有 `endstream` 字样属正常，按 `/Length` 界定即可。
8. 中文路径用 `pathlib.Path` 原样传参，注意 macOS NFD/NFC 归一化，别用 glob 匹配后再做字符串 `==`。

## 校验（用现成 venv，零安装）
`python3` 里有 PyMuPDF，可做只读校验：

```python
import fitz, hashlib
d = fitz.open(输出路径)
assert len(d) == 期望页数
for i, p in enumerate(d):
    w, h = p.rect.width, p.rect.height          # 必须等于目标纸张尺寸
    imgs = p.get_images(full=True)
    info = d.extract_image(imgs[0][0])
    # 关键：哈希必须与源 JPEG 完全一致，证明没有重编码
    assert hashlib.sha256(info["image"]).hexdigest() == 源哈希[i]
    bbox = p.get_image_bbox(imgs[0])            # 版面占位，确认白边/裁切
    assert abs(info['width']/info['height'] - bbox.width/bbox.height) < 0.001  # 无变形
d[0].get_pixmap(dpi=90).save("预览.png")         # 渲染出来目视确认，看完删掉
```

## 关于 DPI
照片像素有限时，铺满 A4 会让实际 DPI 掉到 90–100 左右（原 1078px 宽铺 281mm ≈ 97 dpi）。
- 属于**源文件固有限制**，要如实告知用户「够日常打印/屏幕看，精细印刷偏低」。
- **绝不做重采样或锐化**——原图即信息上限，插值只会变糊、锐化会出光晕。要更清晰只能换更高分辨率原图。
- 可建议用户打印时在驱动里选「按纸张大小缩放/适合页面」，由驱动做高质量缩放。
